# Bilder der README

- `gen_hero.py` erzeugt die Szene mit gpt-image-2.5-flare (Schlüssel aus der Umgebung,
  `OPENAI_API_KEY`); `hero-roh-0.png` ist die verwendete Fassung.
- `hero_bauen.py` setzt das echte Bildschirmfoto `03-schnellstatus.png` in den grünen Bildschirm
  und legt Logo und Titel scharf darauf (Inter, Navy `#07101F`/`#0E2246`, Gold `#C49B18`).
- `streifen.py` baut die beiden Bildstreifen aus den Bildschirmfotos.

Die Bildschirmfotos stammen aus dem Emulator mit einem erfundenen Verlauf; die Skripte erwarten
sie und das Blackfort-Logo `logo-gold-transparent.png` im selben Ordner.
